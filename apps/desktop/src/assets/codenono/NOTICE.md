# CodeNoNo 角色资产说明

## 用途

作为 `@pet/desktop` 桌宠的 spritesheet 皮肤角色（`petId: 'codenono'`），
经 `SpritesheetVisual` 组件按帧切片播放。网格规格与动作映射见
`apps/desktop/src/pet/spritesheet-manifest.ts`。
