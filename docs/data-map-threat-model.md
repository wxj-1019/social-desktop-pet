### 1.2 数据流

```text
客户端(renderer) ──HTTPS──▶ Supabase API/Edge Functions ──▶ PostgreSQL(RLS)
      │                              │
      │◀──HTTPS/WSS(Realtime)────────┘
      │
      ├──▶ AI Gateway(Edge Function) ──▶ 模型供应商 API（经 HTTPS，密钥服务端）
      │
      └──▶ Windows 凭据管理器（refresh token，本机）
```

关键边界：

- **模型供应商密钥永不进客户端**（8.3）——只存在于 Edge Functions 环境变量
- AI 请求上下文在云端内存构造，**不落库**（D11）
- embedding 按明文等价物对待（11.2 第四道：静态加密）

### 2.3 信任边界

```text
┌─────────────┐    ┌──────────────┐    ┌──────────────┐
│ 渲染进程     │    │ Preload(桥)   │    │ Main 进程    │
│ 不可信(UI)   │───▶│ 最小API       │───▶│ 受控(Node)   │
└─────────────┘    └──────────────┘    └──────┬───────┘
                                              │ HTTPS/JWT
┌─────────────┐    ┌──────────────┐    ┌──────▼───────┐
│ 模型供应商   │◀───│ AI Gateway   │◀───│ Edge Function│
│ 处理者       │    │ 密钥持有者    │    │ 校验身份     │
└─────────────┘    └──────────────┘    └──────────────┘
```

边界要点：

1. **渲染进程不信任**：不持有 Node 能力、不持密钥、只能通过 preload 最小 API 通信（8.3）
2. **客户端不信任**：服务端从 JWT 取身份，不信任 Payload 的 userId（9.4）
3. **模型不信任**：模型输出是数据不是指令；动作意图由本地状态机审批（7.1）；权限在模型外（10.7/11.9）
4. **AI Gateway 不信任模型供应商返回**：结构化输出契约 + 输出审核（10.2/10.1）
