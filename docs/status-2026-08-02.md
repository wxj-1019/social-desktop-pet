## 二、架构现状速览

```
桌面端（Electron + React）
├── main/：8 控制器（Window/Display/Tray/Startup/Update/Session/DeepLink/SecureStorage）
│   ├── session-service.ts   真实 Auth API（refresh token 只在主进程 safeStorage）
│   ├── update-source.ts     manifest 检查（stable/beta）
│   └── ipc/register.ts      allowlist + zod 校验
├── src/app/：登录页 / 好友页(tab) / 聊天面板 / 本地聊天 / App 会话状态机
├── src/lib/：api client（401 刷新重试）/ sse 解析 / realtime WS / local-mode / device
└── src/pet/：PetStateMachine + motion 映射 + ModelLoader 骨架（V-1 门禁）

后端（apps/server，Node + Postgres）
├── routes/：auth / business(gift,invite,visit,sync,queries) / chat(SSE)
├── auth/：jose JWT（15min）+ refresh 轮换即撤销（sha256 哈希）
├── realtime/ws.ts：鉴权握手 + ping/pong + 收件箱投递 + 在线状态
├── ai/llm.ts：OpenAI 兼容流式客户端（密钥只存服务端 env）
└── migrations/：0000（自建 auth 兼容层）～0005（inbox_seq/visits bond 可空）

共享包
├── @pet/ai-graph：状态图 runtime + chat-flow（llm 注入式）+ memory-extract 图
├── @pet/protocol：单一真相源 zod schema
└── @pet/pet-state：PetStateMachine（纯逻辑）
```
