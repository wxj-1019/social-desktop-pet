**桌宠修复（四类问题，全部经真实截图 + e2e 验证）。**

| 问题                                       | 根因                                                                                                                      | 修复                                                                                                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 气泡被窗口上边缘裁掉 + 永不消失 + 深色不搭 | `bottom: 94%` 定位；无任何 `text:null` 发送方                                                                             | 顶部锚定不裁切；奶白+莓粉棉花糖气泡 + 指向头顶的尾巴；`use-pet-runtime` 5s 无更新自动消失                                                                            |
| 角色偏小/悬空/偏左，配色与面板割裂         | viewBox 内容只占窗口 ~65%，脚底空 56px；紫色光环/青色星星是旧星空色                                                       | 构图框 `translate(-1 33) scale(1.15)`：贴底居中放大（约 81% 窗高）；光环/星光改暖粉奶油金；渐变 ID 按实例 `useId` 唯一化（面板多头像共存）                           |
| 拖动卡死（松手后仍拖着窗口）               | 无指针捕获；甩出窗口后 `pointerup` 丢失                                                                                   | `setPointerCapture` + `pointermove` 中 `buttons===0` 自愈 + 隐藏/穿透时主进程 `drag.cancel()`                                                                        |
| 说话"双嘴"、点尾巴误触 body                | 闭合 w 嘴与张嘴椭圆同显；尾巴/身体 hit 矩形重叠                                                                           | `data-speaking`/`data-motion='talk'` 时隐藏闭合嘴，reduced-motion 下静态张嘴；尾巴 hit 右边界收到 x86                                                                |
