# 角色生成方案分析：AI 生成 vs 外包（V-12 决策依据）

> 背景：2026-08-01 用户提出"角色不外包，AI 生成很方便"，V-12（Live2D 角色外包制作，预算 ¥15–50 万）待重新决策。
> 约束：设计稿 0.2-8（单原创角色）、8.8（Live2D 许可门禁，V-1 已发出）、7.4（羁绊三阶段）、D-5（角色吸引力验证）、14.2 第 0–1 周。
> 本文评估三条路径的可行性、周期、成本与风险，供选型。

---

## 路径对比总览

| 维度           | A. AI 出图 + 手动拆件绑骨                   | B. 全自动生成 Live2D 模型          | C. AI + 非 Live2D（Spine 等）     |
| -------------- | ------------------------------------------- | ---------------------------------- | --------------------------------- |
| 保持 Live2D 栈 | ✅ 是（8.8 许可流程不变）                   | ⚠️ 是（若工具真能输出 .moc3）      | ❌ 否（改技术栈）                 |
| 周期           | **1–3 周**（立绘快 + 拆件绑骨）             | 最快（若工具可用）                 | 1–3 周（同 A + 换引擎）           |
| 成本           | **≈ 0–¥1 万**（AI 订阅 + 可选绑骨外包单点） | 工具订阅费                         | 同 A + 引擎授权                   |
| 美术技能要求   | **中**（拆件/绑骨是手艺活）                 | 低                                 | 中                                |
| 可控性/迭代    | ✅ 高（不满意重出立绘）                     | ⚠️ 依赖工具输出                    | ✅ 高                             |
| 表现力         | ✅ Live2D 细腻网格形变                      | ⚠️ 待验证（动作网格/物理模拟质量） | ❌ Spine 弱于 Live2D（调研 §3.5） |
| 主要风险       | 拆件质量、AI 同质化、AI 商用授权            | 工具不成熟/被锁定、质量不可控      | 弃 Live2D 许可路径、表现力降级    |

---

## 路径 A：AI 出图 + 手动拆件绑骨（推荐）

**流程**：AI 生成角色正视图立绘 → PS/工具拆部件（头发/身体/四肢/表情层）→ Live2D Cubism 绑骨 → 制作 10 组动作（待机/行走/坐/睡/开心/难过/惊讶/挥手/触摸/口型）。

**优点**：

- 周期 1–4 个月 → **1–3 周**（立绘 1–2 天可出多版，拆件绑骨是主要耗时）
- 成本 ¥15–50 万 → **几乎为零**（AI 订阅 + 自己时间）
- **8.8 Live2D 许可流程完全不变**（V-1 已发出，模型仍是我们"自己创作"——满足 EULA 要求）
- 迭代快：D-5 概念测试可直接用 AI 多版对比
- 全程自控，不依赖供应商排期

**风险与缓解**：

| 风险                                            | 缓解                                                                                                                             |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **拆件/绑骨是手艺活**（决定角色观感与动作质量） | 自己学（Live2D 教程 + 1–2 周上手）；或**单点外包绑骨**（约 $300–3000/角色，远低于一条龙）——"AI 出图自己 + 绑骨外包"是 A 的混合版 |
| **AI 立绘同质化**（"二次元萌系"vibe 趋同）      | D-5 概念测试刻意做差异化（剪影/配色/气质）；用角色 LoRA/ControlNet 锁定形象                                                      |
| **AI 商用授权**（生成工具条款）                 | 选商用授权明确的工具（付费版 Midjourney/本地 SD/即梦等，逐工具查条款）；保留生成参数与工作流记录（证明创作过程）                 |
| **拆件困难的立绘结构**（手部/发丝/透明件）      | 生成时提示词约束（正面/简约结构/无复杂手势）；必要时局部重绘                                                                     |
| **一致性**（多表情/多姿态同一角色）             | 角色 LoRA 或 ControlNet 参考图锁定                                                                                               |

**结论**：作为主路径。**唯一硬依赖是绑骨技能**——若团队无人会，采用"AI 出图 + 绑骨单点外包"混合。

---

## 路径 B：全自动生成 Live2D 模型（评估为高风险）

**现状**：端到端"AI 提示词 → 可直接运行的 .moc3"在 2026-08 尚未形成公认成熟的主流工具（多为半自动/辅助）。需要先验证是否存在满足以下条件的工具：商用授权明确、输出 .moc3 可导入 Cubism SDK、动作/表情/口型质量达标。

**风险**：

- 工具不成熟或不存在 → 路径直接不可行
- 输出质量（网格形变/物理模拟）与手绑差距大，桌宠核心卖点（细腻表情）受损
- 依赖单一工具 = 被锁定；工具停更则资产不可维护
- 工具的模型是否满足 Live2D"我们自己创作"的许可前提需逐条核对

**结论**：**不建议作为主路径**。可作为第 1–2 周的一次快速验证（半天）：若找到可用工具且质量达标，作为 A 的加速器；否则回落到 A。**不阻塞主流程**。

---

## 路径 C：AI + 非 Live2D（Spine/E-mote）

**问题**：

- 调研 §3.5：**Spine 无网格形变，"萌系桌宠"表现力明显弱于 Live2D**；E-mote 接近但按平台收费、无免费豁免（比 Live2D Small-Scale 更贵）
- 放弃 Live2D 栈 = 8.8 许可流程作废（V-1 白发）、8.1 技术选型重做、模型不可复用
- 桌宠的"细腻表情/口型"是核心体验（7.1/10.2），降级风险高

**结论**：**不推荐**。仅在 Live2D 许可被书面拒绝（V-1 回复）时才作为备选评估。

---

## 建议决策

**选 A（AI 出图 + 手动拆件绑骨），绑骨技能按团队情况二选一**：

1. 团队成员现学（1–2 周上手，周期 +1–2 周）
2. 绑骨单点外包（约 $300–3000，周期约 1 周）

同时保留第 1–2 周对路径 B 的**半天快速验证**（不阻塞）。

**对设计稿的影响（选定后需更新）**：

- 14.2 第 0–1 周："启动原创角色外包制作" → "启动 AI 角色生成工作流（立绘 + 拆件绑骨）"
- 12.6 成本表：移除角色外包预算（若绑骨外包则计入 $300–3000 一次性）
- 决策清单 V-12：改为"AI 角色生成 + 可选绑骨外包"
- D-5 角色概念测试：提前到第 1 周（AI 可快速多版对比）
